# 刘潇阳 · EK 小时线核验

本目录是 **刘潇阳** 对 News-AI-quant-project 查询系统「小时线价格与时间是否可信」的人工核验交付物，对应 EK 提出的验收要求。

- 核验时间：2026-11-01
- 核验对象：本仓库查询系统（一小时线库，覆盖 2024-11-04 ~ 2026-10-30）
- 核验方式：**全部走接口与数据库取值**，逐点保留原始返回值与可复跑命令，不使用截图

## 结论

| 项目 | 结果 |
|---|---|
| 抽样 10 点（0883 / 0857 / 0386 / XOM / BZ=F 各 2 点）时间对齐 | **10 / 10** |
| 抽样 10 点收盘价完全一致 | **8 / 10** |
| 剩余 2 点 | BZ=F 各差 1 个最小跳动（0.009%），因系统按到期换月到 BZF27、外部取当月连续 |
| 两年全区间审计（港股各 490 个交易日） | 收盘价一致率 **98.8% / 98.2% / 98.8%** |
| XOM（499 个交易日） | 85.2% 在 0.05 以内，98.6% 在 0.2 以内 |

## 核验发现的三类问题

1. **Windows 下页面打不开（已修复，提交 `3c830df`）**：`.mjs` 被服务端以 `text/plain` 返回，浏览器拒绝执行 ES Module，前端脚本完全不运行——下拉框只剩 7 个静态默认标的，5 个目标标的都选不到。
2. **半日市缺最后一根 bar（已接入检测与标记，提交 `3c830df`）**：平安夜、除夕、农历年前夕和美股提前收盘日会少一根 30 分钟 bar，导致当日收盘价被错取。新增 `quality` 体检命令与查询侧 `incomplete_session` 标记，不再静默出错。
3. **布伦特连续合约未做换月调整（未修，仅标注）**：换月日会出现价格台阶（如 2026-04-07 从 111.49 掉到 94.06 并维持），事件研究若落在换月日附近会算出 ±10% 假涨跌。

## 如何复跑

```bash
# 1) 覆盖体检：每个交易日最后一根小时线是否覆盖到收盘
python -m news_price_query quality --db prices.sqlite3 --format table
python -m news_price_query quality --db prices.sqlite3 --fail-on-gaps   # CI 用

# 2) 逐点对照：查询系统 vs 任意外部源
python scripts/crosscheck_hourly.py --db prices.sqlite3 \
  --as-of 2026-10-31T12:00:00+08:00 \
  --reference 刘潇阳/刘潇阳_参考数据_外部源.csv \
  --point 0883.HK=2026-10-22T10:31:00+08:00
```

参考值来源不限：Yahoo 导出、东方财富、雪球、人工抄录都能用，换源只换 CSV。
